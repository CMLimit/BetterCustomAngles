# 更好的自定义角度（BetterCustomAngles）

《冰与火之舞》Unity Mod Manager 模组，针对关卡编辑器的自定义角度模式。

## 安装

最简单：把 `dist/BetterCustomAngles-0.2.0.zip` 直接拖进 Unity Mod Manager 安装。zip 内是 `BetterCustomAngles/` 文件夹，包含 `Info.json`、DLL 和 `Lang/`。

手动安装：把 `BetterCustomAngles.dll`、`Info.json` 和 `Lang` 文件夹放到：

```
A Dance of Fire and Ice/Mods/BetterCustomAngles/
```

UMM 里启用后进入关卡编辑器即可。本项目已在游戏 **3.3.1** 上部署测试。

## 发布包 / 源码

- `dist/BetterCustomAngles-0.2.0.zip`：UMM 安装包。
- `dist/BetterCustomAngles-source-0.2.0.zip`：源码压缩包。
- `source/BetterCustomAngles/`：干净的源码目录，可直接上传 GitHub。

## 功能

- **扁平化自定义角度 UI**：普通 / 中旋两个按钮、深色圆角输入框、底部工具按钮；保留原版所有放置逻辑和公式计算。
- **模式切换按钮**：右下角按钮显示 `∠` 表示当前是自定义角度模式，显示 `8` 表示八方向模式；原版切换时不会再闪出旧图标。
- **正多边形计算器悬浮窗**：输入边数 n，按 `(n-2)*180/n` 计算内角，最多显示 6 位小数；可直接普通/中旋放置，并自动给该角度加上“n 边形 / n polygon”备注。
- **角度历史悬浮窗**：记录通过自定义角度放置的角度（含公式、多边形、历史/收藏放置），最近使用的排在最前；每行都有“普通”“中旋”两个放置按钮、删除按钮和收藏星标。
- **角度收藏悬浮窗**：点历史行右侧星标收藏；收藏顺序固定，不会因为使用而移动。
- **角度备注**：历史/收藏行中角度右侧的小字就是备注；多边形生成的角度会自动备注。点击小字可编辑备注，备注会保存。
- **窗口可拖动、位置记忆**：窗口只能拖到屏幕内（保留 24px 边距）。
- **位置复位**：卡片右上角「复位 / Reset」按钮；UMM 模组设置里也有「重置窗口位置」。
- **多语言（i18n）**：内置中文、English；可在 UMM 设置里选择语言，也可点卡片标题旁的小按钮快速切换中/英。语言文件位于 `Lang/`，新增 `xx-XX.json` 即可扩展语言。

## 使用

1. 在编辑器里选中一个砖块。
2. 点右下角的 `∠` 按钮切换到自定义角度模式。
3. 输入角度或公式（如 `1*180+26`），按 Enter 或点「普通 / 中旋」放置。
4. 用卡片底部的「多边形 / 历史 / 收藏」打开悬浮窗。
5. 点击历史/收藏行角度右侧的小字编辑备注；点 `×` 删除该条历史；点星标收藏。

角度归一化沿用原版 `%360`：例如 540 → 180，206 仍是 206。最多显示/保存 6 位小数。

## 添加语言

在 `Mods/BetterCustomAngles/Lang/` 下新建例如 `ja-JP.json`，内容为键值对（可复制 `en-US.json` 后翻译）：

```json
{
  "language.name": "日本語",
  "common.normal": "通常",
  "common.midspin": "ミッドスピン",
  "history.title": "角度履歴"
}
```

未翻译的键会自动回退到 English。新语言文件需要重启游戏后出现在语言列表中。

## 说明

- 历史只记录自定义角度，不记录 Q/W/E 等默认角度键。
- 如果窗口被拖到编辑器右侧、被游戏自带面板遮住，点卡片右上角「复位 / Reset」或 UMM 里的「重置窗口位置」即可恢复。
- 数据文件：`angles.json`（历史、收藏、备注）、`settings.json`（语言、窗口位置、历史上限）。
- 构建命令：

```
dotnet build -c Release -p:DeployMod=true
```

`DeployMod=true` 会自动复制到默认 Steam 安装目录；如路径不同，可传 `-p:ADOFAI_PATH="你的游戏目录"`。
